# MediCab - Gestion de Cabinet Médical

Application de bureau en Java / JavaFX pour gérer un cabinet médical.

---

## Fonctionnalites

- Tableau de bord : statistiques patients, maladies, rendez-vous du jour
- Gestion des patients : ajout, modification, suppression, recherche
- Gestion des maladies : catalogue avec code, categorie, description
- Gestion des rendez-vous : planification avec liaison patient/maladie
- Authentification avec roles : Admin et Secretaire

---

## Technologies

- Java 17
- JavaFX 17
- MySQL 8
- JDBC
- Maven
